## A lacuna

Ninguém ocupa com clareza a posição:

> **"A biblioteca de prompts para pesquisa médica, em português, construída por médico, com método científico e verificação embutidos."**

Três provas para sustentar essa promessa em todo conteúdo:

1. **Método**: cada prompt nasce de um framework reconhecido (PICO, PRISMA 2020, CONSORT, RoB 2, GRADE, IMRaD).
2. **Segurança**: todo prompt obriga a IA a citar trecho e página, a responder "não consta" quando a informação não estiver no texto e a nunca inventar referência.
3. **Pronto para uso**: copiar, colar, trocar as [VARIÁVEIS] e pronto. Funciona em qualquer IA.

### Sobre "a melhor biblioteca"

Superlativo sem prova é fraco em marketing e arriscado para um médico. A **Resolução CFM 2.336/2023** (em vigor desde março de 2024) proíbe ao médico postura sensacionalista ou autopromocional e concorrência desleal, e o Código de Defesa do Consumidor proíbe propaganda enganosa. A paper.ai__ é um produto educacional, não um serviço médico, mas quem está por trás é um médico. Então:

- **Evite:** "a melhor biblioteca de prompts do Brasil".
- **Prefira o que dá para demonstrar:** "a biblioteca de prompts feita por médico para pesquisa médica", "prompts testados em artigos reais", "cada prompt baseado em um framework científico", "do PICO ao abstract: um prompt para cada etapa".
- Depoimentos de alunos: sóbrios e sem promessa de resultado (aprovação, publicação).

## Roteiro de benchmark manual (30 minutos no celular)

Como eu não consigo entrar no Instagram daqui, este é o passo a passo para você mesmo coletar os dados. Depois é só mandar os prints para eu analisar.

1. Na busca do Instagram, pesquise: `prompts pesquisa`, `IA para médicos`, `ChatGPT medicina`, `NotebookLM`, `medicina baseada em evidências`, `TCC medicina`, `residência médica IA`.
2. Escolha **10 perfis**: 5 do nicho (IA + medicina/ciência) e 5 de IA em geral que vendem algo.
3. Em cada perfil, abra os **3 carrosséis com mais comentários** das últimas 8 semanas e anote na tabela:

| Perfil | Seguidores | Tema do carrossel | Gancho do slide 1 (copie o texto) | Nº de slides | CTA final | Palavra-chave de comentário? | Comentários | O que vende (link da bio) | Preço |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |

4. Tire print do **slide 1 e do último slide** de cada um.
5. Anote padrões: que ganchos se repetem? Quais promessas? Que objeções aparecem nos comentários ("funciona no ChatGPT grátis?", "serve para TCC?")? As objeções viram carrosséis.
